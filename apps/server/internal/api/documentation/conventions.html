Pagination

Resource collections such as customers, connections, messages and conversations return data with cursor metadata. Pass meta.after back as after to get the next page.

Next page 
curl --get "$WAPO_URL/v1/customers" \
  -H "X-API-Key: $WAPO_API_KEY" \
  --data-urlencode "after=<meta.after-from-previous-response>"

Stop when meta.has_more is false. Treat cursors as opaque values. Resource pages default to 50 items; use limit to request 1–100. Events and delivery history have endpoint-specific limits; check the reference instead of assuming every endpoint uses cursors.

Errors and rate limits

Wapo errors use an error object with a machine-readable code and a human-readable message. Some upstream Graph responses preserve Meta's own error structure.

Example / 401 
{ "error": { "code": "unauthorized", "message": "Invalid API key" } }
Status What to do
400 / 422 Correct the JSON, parameters or validation error.
401 / 403 Check the key, its tenant, account state and administrator scope.
404 The resource does not exist in the authenticated tenant.
409 Resolve the state conflict or uncertain idempotent request.
429 Wait for Retry-After before retrying.
501 / 503 The feature is not implemented or a required service is not configured.

Tenant API requests are limited to 300 per tenant per minute per API process. Console login is limited to 10 attempts per remote IP per minute per process. Distributed deployments need a shared edge limit.

Idempotency and retries

Send a stable Idempotency-Key when creating a message or replying. Reusing a key with the same request replays the recorded result; reusing it with a different request returns a conflict. The key is scoped to the tenant.

A timeout does not mean a message was not sent.

If the provider outcome is unknown, Wapo keeps the reservation and returns a conflict on retry. Reconcile messages and webhook events before submitting a new key. The SDK does not automatically retry sends.

Platform administration

Administrator endpoints manage tenants, users and tenant API keys. Use a console session or a separate operator credential. Creating a tenant does not automatically issue an integration key.

Deleting a tenant removes its local resources and keys permanently. Deleting a user revokes all of that user's sessions. The last active administrator cannot be deleted or deactivated.

WhatsApp is the only channel currently enabled in the public deployment. Automatic carrier provisioning, shared provider billing and managed reconnect are not available in standalone mode. The compatibility reference labels operations with limited support.
