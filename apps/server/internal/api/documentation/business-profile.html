02 / WhatsApp

Manage the business profile

The WhatsApp Business profile is attached to a phone number and is visible from conversation headers. Open Connections → connection → Profile to edit About text, description, address, contact email, category and up to two websites.

Meta remains the source of truth. Wapo reads the profile directly from Meta and reloads it after every update. Profile fields are not mirrored into PostgreSQL.

The console displays the current profile image. Changing it requires a Meta resumable-upload handle, so image upload is not yet available in the console. API consumers that already have a handle can send profile_picture_handle through the native update endpoint.

Update a connection profile 
curl -X PATCH "$WAPO_URL/v1/connections/CONNECTION_ID/business-profile" \
  -H "X-API-Key: $WAPO_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "about": "Atendemos todos los días",
    "description": "Soporte y ventas por WhatsApp",
    "email": "soporte@example.com",
    "vertical": "PROF_SERVICES",
    "websites": ["https://example.com"]
  }'

Graph-compatible clients can use GET/POST /meta/whatsapp/v24.0/{phone_number_id}/whatsapp_business_profile instead. Both paths use the encrypted credential of a connection owned by the authenticated project.
