04 / Operations

Email notifications

Wapo sends connection alerts and project summaries through SMTP. The adapter works with a standard SMTP provider and the Amazon SES SMTP interface. Credentials stay in the server environment; project preferences and the durable delivery outbox live in PostgreSQL.

Configure the mail server

.env / SMTP with STARTTLS 
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USERNAME=<smtp-username>
SMTP_PASSWORD=<smtp-password>
SMTP_FROM_ADDRESS=notifications@example.com
SMTP_FROM_NAME=Wapo
SMTP_TLS=starttls

Use starttls for port 587, tls for implicit TLS on port 465, and none only with a trusted local development server. Never expose these values through VITE_* variables.

Amazon SES SMTP

Use the regional endpoint and SES-specific SMTP credentials. AWS access keys are not SMTP credentials. Verify the sender or its domain and request SES production access before sending to unverified destinations. 

SMTP_HOST=email-smtp.us-east-1.amazonaws.com
SMTP_PORT=587
SMTP_USERNAME=<ses-smtp-username>
SMTP_PASSWORD=<ses-smtp-password>
SMTP_FROM_ADDRESS=notifications@example.com
SMTP_FROM_NAME=Wapo
SMTP_TLS=starttls

Recreate the services after changing the environment:

docker compose up -d --build migrate api worker

Choose recipients and events

Open Console → Configuration → Notifications. The recipient control suggests active people with access to the current project. Select a suggestion, or type any valid external address and press Enter or comma. You can save up to ten explicit addresses.

No explicit recipients? Wapo sends the notification to every active console user with access to that project, including users with all-project access. Membership is resolved when the delivery is queued.
Notification When it is generated
WhatsApp disconnected A connection health check transitions to an error.
Customer needs attention An associated connection develops a warning or error.
Daily statistics Metrics for the previous UTC day.
Weekly statistics Metrics for the last complete UTC week.

Retries and troubleshooting

Email jobs are durable and retry up to eight times with backoff. Delivery is at least once, so a crash after SMTP acceptance can produce a duplicate. Check worker logs and run docker compose run --rm api operations to inspect failed_notifications. Confirm TLS mode, sender verification, SES Region and sandbox status when delivery fails.

Invite project members

With SMTP configured, Console → Users → Invite user creates an inactive account and queues “Te invitaron a Wapo”. The button in that email opens a public acceptance page where the invited person creates their password. The single-use link expires after seven days; the account becomes active only after acceptance.

Wapo stores the validation token as a hash and keeps only an encrypted copy for the durable email job. If SMTP is not configured, the administrator must provide an initial password and the account is activated immediately, which preserves local installations without a mail server.
