Contacts and marketing consent

Wapo creates a typed contact for every person and WhatsApp connection. Use Console → Contacts to search, edit local display data, filter marketing status or permanently erase a contact.

Marketing consent is read-only and scoped to one business number. A missing preference means marketing is allowed. Meta user_preferences webhooks and error 131050 can stop marketing; a later provider resume restores it.

Suppression happens before Meta. Known MARKETING templates for a stopped contact return 422 marketing_preference_stopped. Utility, authentication and in-window free-form messages remain available.
Find stopped contacts 
curl "$WAPO_URL/v1/contacts?marketing_status=stopped" \
  -H "X-API-Key: $WAPO_API_KEY"

Real transitions emit whatsapp.contact.marketing_preference_changed. Permanent erasure removes related local data in one transaction, but cannot recall webhooks already delivered to external systems.
