Templates

Templates belong to a WhatsApp Business Account. Connections sharing that account see the same templates. 

curl "$WAPO_URL/v1/connections/CONNECTION_ID/templates" \
  -H "X-API-Key: $WAPO_API_KEY"

curl -X POST "$WAPO_URL/v1/connections/CONNECTION_ID/templates" \
  -H "X-API-Key: $WAPO_API_KEY" -H 'Content-Type: application/json' \
  -d '{"name":"order_update","language":"es","category":"UTILITY","components":[{"type":"BODY","text":"Recibimos tu pedido."}]}'

Creation submits the template to Meta for review. It does not imply approval. For customer routes, pass connection_id to select the account.

Template change notifications

Subscribe your webhook to whatsapp.template.status_changed, whatsapp.template.category_changed, whatsapp.template.category_change_scheduled and whatsapp.template.quality_changed.

Events include the current template, previous snapshot, revision and source. In Meta, enable message_template_status_update, template_category_update and message_template_quality_update. The worker reconciles pending accounts after one minute and others after six hours, subject to queue size and provider limits.

Scheduled category changes do not replace the effective category until Meta applies them. Repeated unchanged snapshots do not create new events. Signed webhook deliveries can be retried; deduplicate their stable event IDs.

The first synchronization establishes a baseline. Earlier changes and transitions between polls cannot be reconstructed. Read the latest 100 changes from GET /v1/connections/{id}/templates/{template_id}/history.

Meta API

Use /meta/whatsapp/v24.0 with a project API key. The server selects the stored connection token. 

curl "$WAPO_URL/meta/whatsapp/v24.0/WABA_ID/message_templates" \
  -H "X-API-Key: $WAPO_API_KEY"

The adapter handles templates, uploads, WhatsApp Flows, profiles, calls, blocks and phone settings. Media and dataset IDs must have been observed through this project. Flow IDs require an existing binding or a verified account context.

Stored reads only include data received by this instance. Reverse pagination, date filters and provider-specific enrichments are not fully matched. Calling endpoints relay signaling; supply your own audio server.

Automatic number provisioning, partner billing, broadcast scheduling, hosted function execution, workflows and agent runs are not implemented in standalone mode.
